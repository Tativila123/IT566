
# IT566 - Expense Tracker

## About the Project

This is a Python application that allows users to add, view, and filter expenses by category. The application saves expenses in a JSON file and allows users to export them to a CSV file.

## Project Structure

- `src/main.py` - Runs the application.
- `src/ui/` - Handles the menu and user input.
- `src/application/` - Contains the expense tracker functions.
- `src/persistence/` - Handles saving and loading expenses.

## How to Run

Open the terminal in the project folder and run:

    python src/main.py
